<summary>How this chart updates</summary>

Usage is collected locally from coding-tool session logs and existing caches. Raw exports stay outside this repository and are deleted after generation. The updater does not submit to Tokscale or refresh provider usage through their APIs.

On my Mac, `launchd` runs this once a day at **19:00 local time**, at background priority, then exits. No watcher or per-message hook. If asleep, the job runs after waking; a powered-off Mac waits until the next scheduled time.

Run either command from this repository:

```sh
node scripts/update-llm-usage.mjs          # Local chart update only
node scripts/update-llm-usage.mjs --push   # Update, commit and push
```

Publication stops if chart files have local edits, the Git index contains staged changes, or the branch cannot be published safely. Unrelated files and commits are not included. If you preview locally first, commit those chart changes yourself before using `--push`.

Set up on another Mac with Node.js and authenticated Git access:

```sh
npm install --prefix "$HOME/Library/Application Support/llm-usage" --save-exact --ignore-scripts --no-audit --no-fund tokscale@4.20.0
node scripts/install-llm-usage-launch-agent.mjs
```

The CLI version is pinned; scheduled runs do not use `npx` or download a new release. Pricing uses the local cache only; the chart reports tokens, not costs. Cursor totals use existing local caches and may lag its latest usage. Reinstall the job if the configured Node.js binary is removed.

Logs stay local at `~/Library/Logs/llm-usage/daily.log`. Disable the schedule:

```sh
node scripts/install-llm-usage-launch-agent.mjs --uninstall
```

Behavioral checks: `node --test scripts/update-llm-usage.test.mjs`.
